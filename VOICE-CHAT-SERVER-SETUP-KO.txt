Fire Crew Launcher R6 - Minecraft 26.2 / Simple Voice Chat 서버 설정 안내
===========================================================

클라이언트
----------
- 런처가 첫 업데이트 때 공식 Modrinth CDN에서 아래 파일을 자동으로 받습니다.
  voicechat-forge-2.6.21+26.2.jar
- 별도로 클라이언트 mods 폴더에 넣을 필요가 없습니다.
- 게임 안에서 기본 V 키로 음성 채팅 설정을 열 수 있습니다.

서버 관리자 필수 작업
---------------------
1. 서버가 Minecraft 26.2 / Forge 65.0.9인지 확인합니다.
2. 아래 공식 페이지에서 같은 Forge 26.2용 파일을 내려받아 서버 mods 폴더에 넣습니다.
   https://modrinth.com/plugin/simple-voice-chat/version/forge-2.6.21%2B26.2
3. 서버를 재시작해 설정 파일을 생성합니다.
   config/voicechat/voicechat-server.properties
4. UltraServers 패널 또는 고객 지원에서 UDP 24454 포트를 열어 달라고 요청합니다.
5. 설정 파일의 port=24454를 유지합니다.
6. 호스팅 업체가 별도 주소를 안내하지 않았다면 bind_address와 voice_host는 비워 둡니다.
7. 접속 후 관리자 명령으로 연결을 확인합니다.
   /voicechat test <플레이어이름>

주의
----
- Minecraft 게임 포트 19003과 음성 포트 24454는 서로 다릅니다.
- 음성 포트는 반드시 UDP로 허용해야 합니다.
- 서버에 모드가 없거나 UDP 포트가 막혀 있으면 런처 설치가 정상이어도 음성 연결 아이콘에
  플러그가 끊어진 표시가 나타납니다.
